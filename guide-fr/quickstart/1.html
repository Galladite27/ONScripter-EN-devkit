ONScripter-EN - Guide de Démarrage Rapide Général: 1 - Afficher du texte

Ouvrez le script et diriger vous proche du bas, jsuqu'à la ligne "`Game goes here.\." Certaines parties du code au-dessus de cette ligne pourront être mentionnées au cours de ce guide, cependant nous allons commencer avec l'élément le plus important d'une jeu roman - le dialogue.

Tout ce qui est mis dans ce script (si vous voulez, retirez la ligne de texte déjà existance dans le squellette et reprenez sur des bases fraîches) vont être interprétés comme du code pour le jeu quand le moteur est exécuté - tout ce qui est au-dessus est lié à l'initialisation du moteur et non pas du jeu lui-même. Le moteur lit les lignes une après l'autre, continuant jusqu'à la fin du script jusqu'à être arrété.

p

Après que nous aillions commencé, un certain nombre de trivia concernant le script: premièrement, le script est coupé en deux sections principales, celle étant le bloc de définition (define) et le bloc programme (start), le bloc de définition contient les information d'intitialisation, et le bloc de programme contient le contenu du jeu. Deuxièmement, chaque ligne avec un point-virgule (;) est considéré par le moteur comme un "commentaire", et ne faisant pas partie du programme. Ces commentaires peuvent contenir n'importe quoi, souvent des notes pour le développeur pour lui-même. Dans le script squelette vous verrez des commentaires annotant tout ce qu'il y a déjà, et marquant clairement les limites du blocs de définition et du bloc programme précédemment nommées.

Afficher du texte

Afficher du texte dans Onscripter-EN est très simple. Pour marquer qu'une ligne est écrite en caractète non-japonais, commencer par un accent grave (`) comme vu dans la ligne de texte déjà présente. Ainsi, vous pouvez mettre tout le texte que vous voulez après, et quand le moteur atteindra cette ligne du script, il affichera simplement la ligne de texte à l'écran. De large portion de dialogue peuvent donc être écrit quasiment mot pour mot.

Code

`Ceci est une ligne de texte valide dans le langage d'Nscripter.

`Cette ligne l'est tout autant!

Warning

Certains symboles, comme le pourcent (%), peuvent avoir une fonctione attribué même à l'intérieur d'une ligne de texte. Ces fonctions, comme la manière de les éviter, sont traités dans le guide complet, en page 1, dans la catégorie "Texte."

Paramètre de mise en pause de clics

Si vous avre déjà essayer d'écrire votre propre ligne de texte dans le script fourni (ce que vous devriez faire, de tout manière!), vous remarquerez que le texte s'affiche sans pause. C'est car nous avons besoin de de dire au moteur de se mettre en pause à la fin de la ligne!

Onscripter-EN a deux "caractère de mise en pause", @ et \, qui quand utiliser à la fin d'une (et/ou même même au milier d'une) ligne de texte va causer la pause du moteur quand il sera atteint, attendant que l'utilisateur clique avant de continuer. La différence ? Un arobase cause une attente simple de texte tandis que la barre oblique va faire attendre pour un changement de page effaçant ainsi les lignes précédentes.

Code

`Ceci est la première page.@

`Comme celle ci.@

`Et aussi celle ci.\

`Celle ligne est sur la seconde page@

`Commce celle-ci.\

Essayez de votre coté!

Tip

Vous pourrez aussi remarquer que l'icone animé indique qu'une ligne de texte est complété et que l'utilisateur peut cliquer change en fonction d'une attente pour une nouvelle ligne ou une nouvelle page. Ces icones sont stoqué dans le dossier "assets", et le moteur a pour consigne de les utiliser dans le script.
