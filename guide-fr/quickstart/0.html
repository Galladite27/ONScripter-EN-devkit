ONScripter-EN - Guide de Démarrage Rapide Général: 0 - Utiliser les fichiers exemples fournis

Un squelette de projet, remplie de ressources génériques prêt à être utilisées avec ce guide de démarrage rapide, peut être trouvé dans la page "ressources" de ce devkit (disponible dans la page d'acceuil de ce devkit). Téléchargez-le, assurrez-vous de choisir le 'general quickstart' et non le projet vide ou le template 'translation focused. Si vous voulez démarrer après avoir suivi ce guide, vous devriez avoir avis de commencer avec le 'blank template'.

Après avoir télécharger le squelette du jeu, extrayez l'archive à un endroit où vous avez les pleins accès. Confirmez que le squelette de jeu fonctionne en démarrant avec l'exécutable adéquathe - onscripter-en-windows.exe sur Windows et onscripter-en-linux sur Linux. Si vous êtes sur Linux, assurez-vous que l'exécutable et les droits d'exécution. Au démarrage du moteur, il devrait apparaitre une fenêtre noire avec le texte "Game goes here." et qui se ferme après avoir cliqué.

En regardant les dossiers, vous verrez plusieurs éléments - le moteur, une police d'écriture (nommée default.ttf), un script (nommé dans le cas présent 0.txt), et plusieurs ressources de jeu comme des images et de l'audios stockés dans des sous-dossiers nommés de la manière approprié. Dans ce guide de démarrage rapide, à moins d'une mention contraire, le seul fichier qui va réellement nous intéréssé est le script. Il contient les instructions pour que le moteur interprétera pour produire le jeu - comme tous les dialogues, quand les images devraient apparaissent, le menu et les options de choix, ainsi de suite; ou, dans d'autre termes, comment il doit agencer les ressources et les avec quel dialogue pour créer le jeu. Pour éditer le script, utilisez n'importe quel éditeur de text comme vim, le bloc-note de Windows ou notepad++ (liste non-exhaustive).

Pendant que vous suivez ce guide, je vous encourage à développer et ajouter des éléments existants du script, en ajoutant vos propres images en suivant la méthode déjà présente dans le projet squelette. Quand viendra le moment de créer votre propre jeu, vous aurez besoin d'ajouter vos propres ressources de jeu au projet, qui, si vous suivez l'exemple du projet squelette, sera juste de copier le processus existant plutôt que de devoir deviner comment faire par vous-même. Quand vous serez plus confiant avec les bases, vous pourrez dérivez de ce guide et faire les choses de manière bien plus créatif.

Bonne chance, programmateur d'NScripter en herbe!
