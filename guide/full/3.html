ONScripter-EN full guide: 3 - standing images

Standing images are an alternative to sprites, made to simplify drawing character sprites which are very often drawn in the same locations with the same basic settings.

Standing images have three "slots," referred to as l, c, and r (for left, centre, and right) which can either have a sprite drawn in them or be empty. There are certain default values provided relating to these slots which can be changed by the user.

Drawing & clearing standing images

Standing images can be drawn using the ld command. It takes three arguments - the position (either l, c or r), the filename / image processing tag of the sprite to draw, and the effect by which to draw it. For example:

Code

ld l,"sprites/character2.png",1

Tip

Since standing images are "slots" which can either be empty or hold a single sprite at a time, if you try and draw a sprite to a slot already containing a sprite, the old one will be replaced by the new one. This saves you from having to clear the slot each time you want to draw to it.

The cl command is used to clear standing images. It takes two arguments - the slot and the effect, as before. This time, a can also be provided as a slot, which will cause all slots to be cleared. For example, this will immediately clear all standing images:

Code

cl a,1

Finally, the tal command is used to change the transparency of standing images. It takes three arguments - the position, the opacity value (0-255), and the effect.

Code

; Draw sprite as immediately translucent rather than drawing then making translucent

ld c,"sprites/sprite.png",0

tal c,200,1

Standing image settings

The co-ordinates of standing images can be set using the underline and humanpos commands; the former sets the Y level of all standing images, while the latter sets the X level of each of the three standing images. You will notice NScripter's Engrish really shining through in some of the standing image related commands, haha.

Both of these commands require not just a print call, but for the images to be re-drawn to their slots with ld for the changes to take effect.

Code

; Reset default values

underline 479

humanpos 160,320,480

The overlapping priority of standing images can be set (without needing to re-draw the sprites) with humanorder, which takes a string containing the three positions' representative letters in decreasing order of priority and the effect; the priority of standing images against sprites (where sprites with a number less than or equal to the priority are drawn above standing images) can be set with humanz, which takes a number as the Z level of standing images.

Code

; Reset default values

humanz 25

humanorder "rcl",1

Warning

As of 2026-06-03, ONScripter-EN has the default for humanz as 499. This is possibly be a bug and may be subject to change.
