ONScripter-EN general quick-start guide: 0 - using the provided template

A template project, populated with sample assets ready for use with this quickstart guide, can be found on the "resources" page of this devkit (available from the homepage of the devkit). Download it, ensuring you choose the general quickstart template and not the blank project or translation-focused template. If you want to start afresh after following this guide, you may then want to begin with the blank project template.

After downloading the template, extract the archive to a sensible location. Confirm the template is functioning by running the appropriate executable - onscripter-en-windows.exe on Windows and onscripter-en-linux on Linux. If on Linux, ensure the file has execute permissions. Upon running the engine, it should present a black screen with the text "Game goes here." which closes after clicking.

Looking at the files, you will see various things - the engine, a font (named default.ttf), a script (named in this case 0.txt), and various game resources such as images and audio stored in appropriately named subdirectories. In this quickstart guide, unless other files are mentioned the only one we primarily care about editing is the script file. This contains the instructions to the engine on what it should do to produce the game - such as all dialogue, when sprites should appear, the menu and choice options, and so on; or, in other words, how it should put together the assets, and with what dialogue, to make the game. To edit the script file, use any plaintext editor such as vim, notepad or notepad++.

While following this guide, I encourage you to play around with expanding on the existing elements of the script, such as by adding in your own images by following the method already present in the template. When it comes to making your own game, you will need to add your own assets to a project, which if you follow the template's example will be a process of copying an existing solution rather than figuring it out for yourself. When you feel more confident with the basics, then you can branch out and do things more creatively.

Good luck, prospective NScripter!
