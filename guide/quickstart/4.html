ONScripter-EN general quick-start guide: 4 - BGM & voicelines

We will now move onto audio. For simplicity, we will be using MP3 audio for BGM and WAV audio for voicelines (as provided by the template). In a real game it is best to use entirely WAV in many cases, since ONScripter-EN has multiple audio systems and DWave, which is one of two WAV-based sound systems, is by far the best and most comprehensive.

Tip

The size of WAV files can be reduced, often by a half, when packing all the assets into a game resources file ready for distribution. This is due to the NBZ compression which is an option provided by the nsamake tool. More on this in the full guide, page 28

BGM

To play BGM, we will use the bgm command. It takes one argument, the filename of the song, which it plays indefinitely on loop.

Code

bgm "bgm/afternoon-in-paris.mp3"

As usual, aliases can be used, which the template project provides.

Code

bgm bgm_paris

BGM playback can be stopped at any point using the bgmstop command.

Voicelines

Although there exist commands to play audio files once, there are simple shorthands for playing numbered voicelines. The v command, which looks a little different to other commands, is the shorthand for playing WAV files.

It is simply typed as vXXX: (with "XXX" being any number of digits), with a normal line of text following - it then plays the voiceline at the beginning of that line of text. The specific file it plays is voice/XXX.wav, with XXX being the number given. For example, the following line will play a zombie moan before printing the line of text to the screen with a clickwait:

Code

v0001: `Braaaaains!@

Putting it all together

The example at the end of the last page could have music and a voiceline added to it like this:

Code

bgm "bgm/afternoon-in-paris.ogg"

bg bg_alley,1

ld l,sp_girl2,2

ld r,sp_miontoko,2

v0001: `"Get a load of this guy!"@
