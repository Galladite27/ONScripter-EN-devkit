ONScripter-EN general quick-start guide: 2 - displaying backgrounds and effects

We will now learn how to draw backgrounds, also covering simple transition effects.

Plain colour backgrounds

The bg command is used to draw backgrounds. To use a command, we simply begin the line with its name, potentially followed by a space and comma-separated values (called "arguments") which tell the command how it should carry out its purpose. In the case of the bg command, the two arguments we must provide are the background to use and the number of the effect by which to transition to it. For now, the effect number will be 1.

To draw a black or white background, you can simply use the word "black" or "white" as the argument.

Code

bg white,1

`The background is white.@

bg black,1

`The background is now black.@

To draw any other colour, provide the RGB value of that colour as a hex code for the first argument. You can use an online RGB colour picker to get this value.

Code

bg #FF0000,1

`The background is pure red.@

bg #FF44FF,1

`The background is purple.@

Tip

If you draw text after changing the colour of the background, you will notice that the background appears dimmed. This dimming is a default property of the "text window" which the text is drawn within, and can be changed or disabled.

Image backgrounds

In order to draw an image background, we can provide the filename of the image for the first argument in speech marks ("") - this is because while "black" and "white" are special values, a file name is a "string," and so must be marked as such with speech marks.. Provide its path relative to the engine; that is, if the image is in the same directory as the engine, simply give its name. If it's in a subdirectory, also provide that. The given example is for the template project.

Code

bg "bg/01.jpg",1

`The background is a street.@

If you look in the files of the template project, you will see that the backgrounds are stored in a directory called "bg" relative to the engine, which is why we begin the filename with "bg/."

String aliases

We can make this easier for ourselves by creating our own "special values" using "string aliases". To do this, we use the stralias command which must be used in the definition block. The template project already has string aliases for the three backgrounds provided; if you want to add your own, please follow that as a template for your own convenience. It accepts two arguments - the name of the alias (the "special value" to assign) and the associated string (in this case, a filename).

Look at this example in the template project:

Code

stralias bg_alley,"bg/01.jpg"

This makes the word bg_alley to refer to the string "bg/01.jpg." With this definition in place, we can use our more human-readable name with the bg command:

Code

bg bg_alley,1

Effects

Up until this point, we have been using effect number 1 for drawing the background, but now we will make our own effects. Effect numbers 0 and 1 are reserved - 0 is a quite technical effect which will not be covered here, and 1 is an instant transition. Effect numbers 2-255 can be defined by the user with the effect command which, like stralias, must be used in the definition block. Though more advanced things can be done with it, we will just cover the usage of the command in terms of built-in effects which ship with the engine.

To assign a built-in effect to an effect number, use the effect command with three arguments - the effect number to assign, the built-in effect number, and the desired duration of the transition in milliseconds. The list of built-in effect numbers which can be used with this command (taken from the API reference) is as follows:

  1. Instantaneous display
  2. Left-sided shutter
  3. Right-sided shutter
  4. Upwards shutter
  5. Downwards shutter
  6. Left-moving curtain
  7. Right-moving curtain
  8. Upwards curtain
  9. Downwards curtain
  10. Pixelwise crossfade
  11. Left-moving scroll
  12. Right-moving scroll
  13. Upwards scroll
  14. Downwards scroll
  15. Fade via mask pattern (ignore for now)
  16. Mosaic out (ignore for now)
  17. Mosaic in
  18. Crossfade via mask (ignore for now)

For example, to define effect number 2 as a 1-second left-moving curtain, we would use the effect command like this:

Code

effect 2,6,1000

Or, in other words, we are telling the engine "define effect number 2 as being built-in effect 6 with a 1000 millisecond duration." After being defined once in the define block, the effect number can then be used as desired throughout the rest of the script.

Tip

Since usage of the effect command can seem cryptic, it may help you to put a comment with each effect you define to tell you in human terms what the effect is.

As before, please refer to the template project to see how it defines effects, and try using them to change the background with yourself.
