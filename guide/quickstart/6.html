ONScripter-EN general quick-start guide: 6 - conclusion and next steps

Congratulations, you've reached the end of the quick-start guide!

Well done for presevering! So, what's next? If you have a particular project in mind, you might as well start making the core of the game, since things like menus can be added later. You could either start working from the template you've been modifying while reading this guide, or if you're confident with how files (such as images and audio) are accessed and how aliases work, you could start from scratch in the separate blank project template provided.

Otherwise, I would recommend re-reading any sections you're not fully confident with, and experimenting in a variety of ways to see what happens (mostly crashes, haha).

If you feel like you've outgrown this quickstart guide and want to read more, or if you want to add something not mentioned here to your game, you could move onto the full guide. I'd recommend reading it from the beginning, even if you end up skimming over sections, just so that you don't miss anything important - since this quickstart guide aimed to get you making a game as quickly as possible, certain decisions were made on your behalf and topics left undiscussed.

Either way, you should definitely try and learn to use the API reference, which is the official documentation for the NScript language. The API reference itself is found in the resources page of this devkit, and a brief guide to reading it is found in the full guide, page 0, under the heading of "Using the API reference." You could also try reading through the define block of the template project you've been working with, checking the API reference as practice to see the meaning and usage of each command there.
