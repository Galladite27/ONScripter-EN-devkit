ONScripter-EN translation-focused quick-start guide: 1 - using the script and game archive tools

When working with existing games, it is very likely that the script and/or game resources will be stored in obfuscated files. To save me from repeating myself, we will in this article cover extracting and repacking script and game archives.

Generic process

In general, each tool will be used in a similar way. Each section below will cover a specific process using a specific tool, but in general, the process will involve (1) copying a program from the archive file tools (available for download from this devkit's resources page) into the same direrctory as the files to be modified, then (2) using cmd (Windows) or another shell (Linux, other) to run that program to have it interact with the appropriate files. In Windows, a terminal can be opened in the current directory from File Explorer by typing cmd in the address bar and pressing enter.

After running the appropriate command and it having completed, the terminal may be closed; also, the old file(s) should be moved somewhere else and replaced with the newly created file(s).

It is important to note that these processes are intended to be used only at the beginning and end of working on a project (at the beginning to make the files accessible for modification, and at the end for distribution) - the engine can read un-obfuscated and un-packed scripts and game resources just fine. So, there is no need to repack script or game archives just for testing - leave them extracted while you work on them.

Extracting script archives (nscript.dat => 0.txt)

To extract a script archive, we will need to use the program named nscdec from the archive file tools. Move that program into the same folder as the obfuscated script file (nscript.dat), open a terminal window in that directory, then run the following command: .\nscdec.exe nscript.dat 0.txt (Windows) or ./nscdec nscript.dat 0.txt (Linux). Move the obfuscated script somewhere safe to ensure the engine reads the extacted script instead of it.

Repacking script archives (0.txt => nscript.dat)

To repack a script archive, we will need to use the tool named nscmake and the command .\nscmake.exe 0.txt (Windows) or ./nscmake 0.txt (Linux). Move the plaintext script somewhere safe to ensure the engine uses this obfuscated script file.

Extracting game archives (*.nsa / *.sar / *.ns2 => multiple files / directories)

Firstly, locate the game archive file(s). The main name you are looking for is arc.nsa, however any file ending in .nsa, .sar or .ns2 will do - just remember the original name.

To extract the archive, we will use the appropriate tool, named after the file type + "dec" (for example, nsadec.exe for an archive named arc.nsa. In a terminal, type the name of the tool, followed by -o out, followed by the name of the game archive file - for example, .\nsadec.exe -o out arc.nsa (Windows) or ./nsadec -o out arc.nsa (Linux). This will extract all the resources from the archive into the new directory named "out."

To make the engine able to read the resources, you will need to take them out of the folder named "out," so that they are in the same directory as the engine. But don't lose track of which files came from the archive, so that we can repack them later. Move the old game archive somewhere safe to ensure the engine reads the extracted files instead of it.

Repacking game archives (multiple files / directories => arc.nsa)

For the sake of this guide, we will create an NSA format game archive, since it is common and supports compression of WAV and BMP files (which these steps will enable).

To repack the archive, you will need the tool nsamake in the same directory as the directory named "out" (created before); ensure that all the resources you want in the archive are put back in the "out" directory. Then, open a terminal in that directory as before, and use the command .\nsamake.exe arc.nsa -d out (Windows) or ./nsamake arc.nsa -d out (Linux). Move the extracted resources somewhere safe to ensure the engine reads the game archive instead of them.

Tip

If the file is of the .nsa filetype, you can enable compression of all .bmp and .wav files by adding the option -e before the -i option (for example, nsamake.exe arc.nsa -e -d out). This will take longer to create the game archive file, and may slightly impact performance in-game on older hardware, but will greatly reduce the size of the file.

Warning

Be careful about not touching the structure of the file hierarchy, and running these tools with the correct options and from the correct directories, otherwise it could cause the engine not to be able to find the rersources, even within the game archive.
