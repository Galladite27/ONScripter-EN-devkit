ONScripter-EN translation-focused quick-start guide: 2 - translating text

Before we begin replacing text in a script, we have to be able to edit the script. As you may remember from the general introduction, ONScripter-EN allows for game scripts to be in either plaintext (likely 0.txt) or obfuscated (likely nscript.dat) formats. To edit, it must be in plaintext format - if it isn't already, then convert it to be.

Also, very rarely, a game may have a script in another format, such as the encrypted nscr_sec.dat and nscript.___ - this is beyond the scope of this guide.

Editing the script

To edit the script (0.txt), open it in a plaintext editor such as vim, notepad or notepad++. Make sure you do not change the encoding of the file. Before the bulk of the text is translated, we will make one simple change - we will put the engine in English mode. This sets certain default values to be in English, amongst other things. To do this, search the script for the line reading *define. Then, directly after it, insert a line reading language english. This command was only implemented in ONScripter-EN, so there is no chance a game made with NScripter will already have a language command elsewhere specifying Japanese.

Translating text

Read through the script, replacing lines requiring translation as you go. Every line which contains simply Japanese text by itself is printed dialogue and will require translating. Some lines containing commands will have text in speech marks "" which requires translating, but some won't. It's up to you to work this out and only translate what is needed - for example, file names should not be changed, since this is not printed text but a reference to a file the engine needs.

Whenever you see text that needs translating, it is very important that you make the first character of the translated text to be a backtick (`) character - this marks the text as being "1-byte" text, letting the engine know when Latin script text should be treated as plain text rather than a command.

If you need to know the meaning of a command to help you determine if its string arguments require translating, please refer to the API reference in the "resources" section of this devkit. A guide to using it can be found in the full guide, page 0, under the heading of "Using the API reference."

Tip

If you want to add notes to yourself, or leave a copy of the untranslated line next to each translated line for future reference, know that any line beginning with a semicolon (;) is a "comment" and will be ignored by the engine - you can write whatever you like there!

Warning

In almost all cases, the game you are translating will be in Japanese, English, or maybe Russian. These languages' characters are supported by the Shift JIS character encoding which NScripter (and by default, ONScripter-EN) uses. If the language you are translating into requires characters not supported by this character encoding, consider enabling UTF-8 mode. This can be done simply by renaming the script from a Shift-JIS name to its equivalent UTF-8 name. For more information (including these names), please see the section "Script files" under page 1 of the full guide.

Examples:

Code

; Line of printed dialogue:

; 私は田中です。@

`My name is Tanaka.@


; A choice presented to the user:

; select "左に行く",*hidari,"右に行く",*migi

select "`Go left",*hidari,"`Go right",*migi


; Non-dialogue line which seems to include text requiring translation:

; rmenu "セーブ",save,"ロード"

rmenu "`Save",save,"`Load"


; Non-dialogue line not in need of translation

stralias screen_blood_1,"CG/ryuuketu1.png"
