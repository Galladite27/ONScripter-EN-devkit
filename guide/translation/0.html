ONScripter-EN translation-focused quick-start guide: 0 - using the provided template

This particular guide is as lightweight as I could reasonably make it, so as to only present the most essential of information to translators who don't care about using the engine except to replace text and other resources in existing games with translated equivalents.

A template project, populated with sample assets ready for use with this guide, can be found on the "resources" page of this devkit (available from the homepage of the devkit). Download it, ensuring you choose the translation-focused quickstart template and not the blank project or general quickstart template.

After downloading the template, extract the archive to a sensible location. Confirm the template is functioning by running the appropriate executable - onscripter-en-windows.exe on Windows and onscripter-en-linux on Linux. If on Linux, ensure the file has execute permissions. Upon running the engine, it should present a black screen with the text "Game goes here." which closes after clicking.

Additionally required for this guide is a set of the archive file tools, available also on the "resources" page of this devkit. Please download and extract the appropriate set of tools for your operating system - their usage will be covered as required in the following pages.

Good luck, translator!
